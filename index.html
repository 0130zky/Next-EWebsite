About Us

我们是谁

十年传承，永不止步

Next-E 战队成立于2015年，是西安理工大学工程训练中心的一支充满激情与创造力的机器人竞赛团队。我们专注于由全国大学生机器人大赛 RoboMaster 机甲大师赛，致力于机器人技术的研发与创新。

战队横跨机械工程与自动化、电气系统控制、计算机科学、视觉算法识别与导航等多个学科领域，由十年来累计千余名名来自不同专业的优秀学子组成。

技术组介绍

五大技术方向协同

Electronic Control

电控组

战车的“小脑与神经”，负责把机械结构变成能跑能打的真车，是连接上层算法与底层硬件的桥梁。

嵌入式开发：主控程序编写与调试，涵盖 STM32 驱动、CAN/SPI/UART 通信、传感器解算与整机链路打通。

控制算法：运动控制与状态反馈，负责闭环算法调参、麦轮与全向轮运动学解算、云台姿态解算与自稳。

技术栈：C 语言 · STM32 · Keil + STM32CubeMX · FreeRTOS。

Mechanical Design

机械组

机器人的骨骼与肌肉，负责整车结构从设计到实物的全流程落地。

结构设计：底盘、云台、弹舱与发射机构设计，覆盖工程仿真与轻量化。

加工装配：零件加工对接、整车装配与迭代调试，让图纸变为能上赛场的真车。

技术栈：SolidWorks · 有限元分析 · 加工工艺 · 3D 打印。

Algorithm & AI

算法组

机器人的大脑，负责视觉感知与决策算法，用模型与数据赋予机器人战场智慧。

视觉感知：自瞄识别、能量机关与目标跟踪算法研究，让机器人“看得见”。

决策控制：弹道解算与预测、路径规划与自主决策，让机器人“想得清、打得准”。

技术栈：Python · C++ · OpenCV · 深度学习 · Linux · ROS。

Software Engineering

软件组

战队的“技术核心”之一，分软件开发与软件宣运两方向，兼顾产品研发与品牌建设。

软件开发：RM 模拟器、自定义比赛客户端、战术分析与可视化工具、战队信息化系统。

软件宣运：官网前后端开发运维、技术内容产出、公众号/B 站运营、赞助商对接。

技术栈：Unity · C# · TS · React · Vue · Node.js · Python；官网：HTML · CSS · JS。

Hardware Engineering

硬件组

机器人的能量与电路基石，负责从原理图到 PCB 制板的全链路自研。

电路设计：主控板与功率驱动板设计，电源管理、传感器选型与信号链路搭建。

板级调试：PCB 绘制、打样焊接与整机调试，保障每一块板子稳定可靠上赛场。

技术栈：Altium Designer · C 语言 · 电源设计 · 焊接与调试。
